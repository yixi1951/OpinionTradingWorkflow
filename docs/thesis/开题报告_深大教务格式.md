## 本选题的意义及国内外发展状况 *

### 本选题的意义：

社交媒体与财经社区（以东方财富股吧为主）产生大量用户生成内容（UGC），时效强但噪声高。既有文献已讨论股吧信息含量与情绪度量，工程上也不乏爬虫与打分演示；但若仅用关键词或影响力加权充当「打分」，度量过粗，难以支撑严肃的可预测性检验。本课题因此把研究设计固定为一条清晰流水线：

**采集 UGC → OpenClaw 免费模型验真/筛噪 → Jev / DeepSeek 正式情绪打分 → 日度因子 → Fama–MacBeth / Logit 测评。**

核心问题（P）：在可控的 A 股个股—交易日样本上，经真实性门控后的社交媒体文本情绪，能否预测未来 1/3/5 个交易日的收益水平与涨跌方向？以 Jev/DeepSeek 得到的情绪因子，相对词典基线是否更有效？

子问题：  
P1（数据与验真）：如何用 OpenClaw 免费模型对采集帖文做可读性/真实性检查，降低灌水、空文与不可解析噪声？  
P2（打分）：在验真通过的样本上，用 Jev / DeepSeek 得到帖级分数 \(s_d\in[-1,1]\)，并聚合为日度因子（主报告看 LLM 日度均值与 Bullishness；词典仅作基线）？  
P3（测评）：Fama–MacBeth（收益）与 Logit（涨跌）在控制滞后收益与关注度后，情绪系数是否显著？结论在 Walk-Forward 等设定下是否稳健？

**样本与因变量边界：** 主文本源为东方财富股吧；股票池取沪深300流动子集约 30–70 只；样本期以可复现采集窗口为准；被解释变量主报告用个股未来 h 日简单收益，稳健性补充相对沪深300超额收益。  

**角色分工（开题承诺）：** OpenClaw = 采集侧验真，不作论文主打分器；Jev/DeepSeek = 正式打分；关键词/影响力加权 = 基线或聚合稳健，**不是**打分替代。  

**识别边界：** 检验可预测性/相关预测，不声称因果。课题依托 OpinionTradingWorkflow，目标是可复现的「验真—打分—检验」闭环，而非承诺实盘超额收益。

### 国内外发展状况：

国外经典研究方面，Antweiler 与 Frank（2004）基于雅虎财经留言板构造看涨指数等指标，讨论网络讨论与市场活跃度、波动及收益的关系，为社交媒体文本进入资产定价实证提供了方法范式[1]。其后大量文献在不同市场与数据源上拓展情绪度量、关注度代理与预测窗口设定，逐步形成「帖级打分—日度聚合—收益回归/分类」的研究路径。

国内方面，段江娇等从股吧文本出发讨论信息含量[2]；杨晓兰等指出情绪效应常与本地关注交互[3]。管理科学学报相关工作突出开盘前情绪对开盘价的影响，提示时间戳须与交易日历对齐[4]。姚加权等提出中文金融情绪词典[5]；万漪萍等从机器学习情绪打分角度讨论股吧情绪与短期收益[6]。王高山等强调影响力加权相对简单均值的优势[7]。尹海员等引入序列模型刻画情绪动态[8]。徐维军等将文本情绪嵌入 Black–Litterman 框架[9]。张维等综述提醒识别策略与数据质量边界[10]。

综合来看，缺口在于：噪声治理与正式 LLM 打分常被拆开讨论；工程演示易用关键词/加权冒充打分；计量上又常缺少规范的 Fama–MacBeth / Logit。本课题以「OpenClaw 验真 + Jev/DeepSeek 打分 + FM/Logit」统一补齐。

## 研究内容 *

本课题按「验真 → 打分 → 测评」三层展开。

一、问题表述与研究假设

研究对象：个股 i、交易日 t 的情绪因子 \(S_{i,t}\)，与未来 \(h\in\{1,3,5\}\) 日收益 \(r_{i,t+h}\)、涨跌 \(y_{i,t+h}\)。信息集仅用 t 日及以前信息，避免前视。  
主假设：经 OpenClaw 验真、并由 Jev/DeepSeek 打分得到的 \(S_{i,t}\)，在控制滞后收益与关注度后，对收益与涨跌具有显著预测力；相对词典基线可报告差异。识别边界：可预测性，非因果。

二、层 A：数据采集与 OpenClaw 验真

主采集东方财富股吧 UGC（可辅以其他平台作子集）。对原始帖文调用 **OpenClaw 免费模型**做可读性/真实性门控：能被稳定解析者标记 `openclaw_validated=1`，失败则筛除或标噪。OpenClaw 可保留临时标量供审计，但**不进入**论文主因子 `sent_llm`。

三、层 B：Jev / DeepSeek 正式打分与日度因子

对验真通过的帖文 d，以 **Jev（jevmodel.org）优先、DeepSeek 为正式备援** 得到 \(s_d\in[-1,1]\)，`score_source∈{jev,deepseek}`。词典分单独保留。  
日度聚合（主报告）：  
- Q4 \(S^{llm}\)：仅对 jev/deepseek 帖取均值（主因子）  
- Q5 Bullishness：基于 LLM 帖的看涨/看跌计数，\(ln[(1+B)/(1+S)]\)  
- Q3 \(S^{dict}\)：词典基线对照  
- Q1/Q2 均值与影响力加权：聚合稳健性，附录/稳健章  

四、层 C：检验模型（测评）

（1）Fama–MacBeth：\(r_{i,t+h}=a_t+b_t S_{i,t}+c_t'X_{i,t}+e_{i,t}\)，对 \(\{b_t\}\) 取均值并报 Newey–West t；主报告对 Q4/Q5（及 Q3 基线）与 h=1/3/5 出表。  
（2）Logit：\(P(y=1)=\Lambda(\alpha+\beta S+\gamma'X)\)，报告 β、AUC、准确率。  
（3）稳健性：Walk-Forward、平台子集、Winsorize、超额收益替换。

五、工程落点

OpinionTradingWorkflow：`crawl_*` 采集 → `validate_raw_openclaw.py` 验真 → `rescore_raw_cascade.py`（Jev/DeepSeek）→ `export_sentiment_panel` / `thesis_models` 出表。股票池约 30–70 只沪深300流动股。

## 研究方法、手段及步骤 *

### 研究方法：

文献界定 → 固定三层流水线（验真/打分/测评）→ 构造 Q3/Q4/Q5 主对照 → 估计 FM 与 Logit → Walk-Forward 与稳健性 → 比较 LLM 因子相对词典基线是否更有效。以可预测性检验为主，审慎声称因果。

### 研究手段：

采集：Python；股吧 API/页面采集。  
验真：OpenClaw 免费模型（`OPENCLAW_URL`）。  
打分：Jev（`https://jevmodel.org/v1/systemone`）与 DeepSeek；`score_source` 溯源。  
计量：Fama–MacBeth、Logit、情绪面板；Git + CSV 复现。

### 研究步骤：

（1）开题定稿：写清三层流水线、P/P1–P3 与基本模型；知网复核文献。  
（2）采集 + OpenClaw 验真，形成可用帖文库并与行情对齐。  
（3）Jev/DeepSeek 覆盖打分，导出主因子 Q4/Q5（Q3 基线）。  
（4）主实证：FM（h=1/3/5）与 Logit 出表。  
（5）稳健性、论文撰写与答辩。
