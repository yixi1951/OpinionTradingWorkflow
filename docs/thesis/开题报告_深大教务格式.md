## 本选题的意义及国内外发展状况 *

### 本选题的意义：

社交媒体与财经社区（股吧、雪球、微博、财经门户评论等）产生的用户生成内容体量大、时效强，但噪声高、结构松散，难以直接服务于投资决策与学术检验。行为金融研究表明，投资者关注与文本情绪可能影响短期价格形成；工程上虽已具备多源采集与情感打分能力，却缺少在**同一流水线**上对「不同情绪量化方式」与「规范计量模型」的系统对照。

本课题要回答的核心问题可表述为：

（问题 P）在可控的 A 股个股—交易日样本上，社交媒体文本情绪能否预测未来 1/3/5 个交易日的收益水平与涨跌方向？何种情绪量化定义更有效？

进一步拆为三个可检验子问题：

P1（度量）：帖级情绪由 **Jev / DeepSeek** 正式打分后，日度聚合为均值、影响力加权稳健项、词典基线与 Antweiler 看涨指数；何种定义对短期预测更有效？  
P2（模型）：连续收益用 Fama–MacBeth 截面回归、涨跌方向用 Logit，在控制滞后收益与关注度后，情绪因子系数是否显著？  
P3（稳健）：结论在 Walk-Forward、平台子集、Winsorize 与不同预测窗口下是否稳健？

**样本与因变量边界（开题承诺）：** 主文本源为东方财富股吧；股票池取沪深300流动子集约 30–70 只；样本期以可复现采集窗口为准（当前工程面板约 2026-09 至近端，可随数据积累上溯）；被解释变量主报告采用个股收盘价计算的未来 h 日简单收益，稳健性中补充相对沪深300的超额收益。  

**数据与打分流水线（策略定稿）：**  
（1）采集 UGC（股吧等）；  
（2）**OpenClaw 免费模型**做可读性/真实性验真与筛噪（不作论文主打分器）；  
（3）**Jev / DeepSeek** 对验真通过的帖文正式打分（`score_source=jev|deepseek`）；  
（4）导出日度因子并跑 FM/Logit。关键词与影响力加权**不是**打分替代——加权仅作聚合稳健性。

**识别边界：** 本课题检验的是**可预测性/相关预测**，不声称情绪对收益的因果识别；内生性通过信息滞后、控制关注度 \(M\)、Walk-Forward 样本外协议缓解，开题阶段不作工具变量承诺。

课题依托 OpinionTradingWorkflow 实验平台，目标不是承诺实盘超额收益，而是形成可复现的「度量—模型—检验」闭环，为理解舆情因子有效性边界提供实证证据。

### 国内外发展状况：

国外经典研究方面，Antweiler 与 Frank（2004）基于雅虎财经留言板构造看涨指数等指标，讨论网络讨论与市场活跃度、波动及收益的关系，为社交媒体文本进入资产定价实证提供了方法范式[1]。其后大量文献在不同市场与数据源上拓展情绪度量、关注度代理与预测窗口设定，逐步形成「帖级打分—日度聚合—收益回归/分类」的研究路径。

国内方面，段江娇等从股吧文本出发讨论信息含量[2]；杨晓兰等指出情绪效应常与本地关注交互[3]。管理科学学报相关工作突出开盘前情绪对开盘价的影响，提示时间戳须与交易日历对齐[4]。姚加权等提出中文金融情绪词典[5]；万漪萍等从机器学习情绪打分角度讨论股吧情绪与短期收益[6]。王高山等强调影响力加权相对简单均值的优势[7]。尹海员等引入序列模型刻画情绪动态[8]。徐维军等将文本情绪嵌入 Black–Litterman 框架[9]。张维等综述提醒识别策略与数据质量边界[10]。

综合来看，缺口在于：多数研究绑定单一平台或单一打分器；工程演示常缺少规范的 Fama–MacBeth / Logit；噪声治理常被省略。本课题以统一实验床补齐多度量对照与正式计量。

## 研究内容 *

本课题围绕上述 P1–P3，先固定**问题表述与基本模型**，再展开数据与实证。

一、问题表述与研究假设（开题先写清）

研究对象：A 股个股 i、交易日 t 的社交媒体情绪因子 S_{i,t}，与未来 h∈{1,3,5} 日收益 r_{i,t+h}、涨跌方向 y_{i,t+h}=1{r_{i,t+h}>0}。  
信息集：仅使用 t 日及以前可得的帖文与行情，严格避免前视。  
主假设：在控制滞后收益与关注度后，S_{i,t} 对 r_{i,t+h} 的截面预测系数及对 y_{i,t+h} 的 Logit 系数显著异于 0；不同度量的预测力存在可比较差异。  
识别边界：检验可预测性，不声称因果。

二、基本模型一：情绪如何量化（对照因子 Q1–Q5）

帖级：对每条验真通过的帖文 d，由 **Jev 或 DeepSeek** 得到 s_d∈[-1,1]，保留 `score_source`（jev/deepseek）。OpenClaw 仅验真；词典分单独保留作基线，**不**与 LLM 分混用。  
标的—日聚合（D_{i,t} 为当日相关帖）：  
Q1 简单均值：S^mean_{i,t} = (1/|D_{i,t}|) Σ s_d（s_d 取正式 LLM 分）  
Q2 影响力加权：S^inf_{i,t} = Σ(w_d s_d)/Σ w_d（聚合稳健性，非打分方法）  
Q3 词典日度：S^dict_{i,t}（同源文本，仅用词典分，基线对照）  
Q4 LLM 日度：S^llm_{i,t}（**仅** score_source∈{jev,deepseek} 的帖）  
Q5 Antweiler 看涨指数：Bullishness_{i,t} = ln[(1+B_{i,t})/(1+S_{i,t})]，主报告基于 LLM 帖分类；另报告关注代理 M 及可选交互 S×M。

**主次安排：** 主报告以 **Q4（Jev/DeepSeek）与 Q5（Bullishness）** 为核心，并以 **Q3（词典）** 为可解释基线；Q1/Q2 为聚合对照进入稳健性/附录。不以关键词或加权代替 LLM 打分。

三、基本模型二：用什么模型检验

（1）Fama–MacBeth 截面回归（主模型 A，连续收益）  
每个交易日 t 做截面回归：  
r_{i,t+h} = a_t + b_t S_{i,t} + c_t' X_{i,t} + e_{i,t}  
再对 {b_t} 取时间均值，报告 Newey–West 稳健 t 值。控制变量 X 至少含滞后收益、关注 M；规模等按数据可得性加入。主报告对 Q3/Q4/Q5 与 h=1/3/5 出表，Q1/Q2 作稳健补充。r 主用简单收益，稳健性补超额收益。

（2）Logit 涨跌分类（主模型 B，方向）  
P(y_{i,t+h}=1) = Λ(α + β S_{i,t} + γ' X_{i,t})  
报告 β、AUC、准确率等，并与无情绪基准比较。

（3）稳健性：Walk-Forward、平台子集、Winsorize、盘前/全日窗、超额收益替换；时间允许时可作 Black–Litterman 应用延伸，不替代主检验。

四、数据与工程落地（支撑上述模型）

主文本源股吧，辅以其他平台作子集稳健；股票池约 30–70 只沪深300流动股；交易日历对齐、去重；**OpenClaw 免费模型验真**后，再以 **Jev/DeepSeek** 打分；在 OpinionTradingWorkflow 上导出对照面板并运行 FM/Logit，保证实验可复现。

## 研究方法、手段及步骤 *

### 研究方法：

文献界定度量与计量设定 → 统一样本上构造 Q1–Q5 → 估计 Fama–MacBeth 与 Logit → Walk-Forward 与稳健性 → 比较何种度量更有效。技术路线：多源采集 → OpenClaw 验真 → **Jev/DeepSeek 正式打分** → 日度聚合 → 合并 1/3/5 日收益与涨跌标签 → FM + Logit → 稳健性 → 论文图表。以可预测性检验为主，审慎声称因果。

### 研究手段：

数据采集与处理：Python、pandas/NumPy；股吧等采集 + OpenClaw 免费模型验真。  
情绪打分：**Jev / DeepSeek**（论文主路径）；词典仅基线；score_source 溯源。  
计量：Fama–MacBeth、Logit、情绪面板导出（export_sentiment_panel / thesis_models）；复用 walk_forward、factor_backtest。  
工程：Git + pytest；CSV/Markdown 落盘保证可复现。

### 研究步骤：

（1）开题定稿：写清问题 P/P1–P3、OpenClaw 验真 + Jev/DS 打分策略与基本模型，知网复核文献。  
（2）面板构建：采集 → OpenClaw 验真 → 行情对齐。  
（3）度量落地：Jev/DeepSeek 覆盖后导出 Q1–Q5（主表看 Q4/Q5）。  
（4）主实证：跑通 FM（h=1/3/5）与 Logit，出主结果表。  
（5）稳健性与论文撰写、答辩。
