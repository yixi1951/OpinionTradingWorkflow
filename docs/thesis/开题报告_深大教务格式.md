## 本选题的意义及国内外发展状况 *

### 本选题的意义：

社交媒体与财经社区（以东方财富股吧为主）产生大量与个股相关的用户讨论文本，时效性强，但同时存在灌水、广告与资讯转载等噪声。行为金融与金融科技交叉研究表明，投资者关注与文本情绪可能影响短期价格形成；若情绪度量定义不清、数据未经质量筛选，或缺少规范的计量检验，则难以支撑严肃的可预测性研究。

本课题拟在统一的 A 股个股—交易日样本上，完成股吧文本的采集与质量治理，构造可对照的日度情绪因子，并用截面回归与分类模型检验其对未来短期收益与涨跌的预测能力。目标是形成可复现的「数据治理—情绪度量—检验模型」闭环，为理解舆情因子有效性边界提供证据；**不承诺实盘超额收益**，**不声称因果识别**。

核心问题（P）：经质量筛选后的股吧文本情绪，能否预测未来 1/3/5 个交易日的收益水平与涨跌方向？基于文本挖掘得到的情绪因子，相对词典基线是否更有效？

子问题：P1（数据治理）如何识别并剔除无效文本？P2（情绪度量）帖级情绪如何度量并聚合为日度因子？P3（检验）Fama–MacBeth 与 Logit 在控制滞后收益与关注度后系数是否显著、稳健性如何？

样本边界：股吧主源；沪深 300 流动子集约 30–70 只；主报告用简单收益，稳健性补充超额收益。

### 国内外发展状况：

国外方面，Antweiler 与 Frank（2004）基于财经留言板构造看涨指数等指标，讨论网络讨论与市场活跃度、波动及收益的关系，形成「帖级情绪—日度聚合—收益回归/分类」的经典路径[1]。

国内方面，段江娇等讨论股吧信息含量[2]；杨晓兰等强调情绪与本地关注的交互[3]；部慧等研究股评情绪及开盘前情绪与价格形成，提示时间对齐的重要性[4]。姚加权等提出中文金融情绪词典[5]；万漪萍等基于机器学习分析社交媒体文本与证券收益[6]。王高山等讨论影响力加权相对简单均值的优势[7]。尹海员等引入序列模型刻画情绪动态[8]。徐维军等将文本情绪嵌入资产配置框架[9]。张维等综述提醒识别策略与数据质量边界[10]。

综合来看，既有文献已分别证明股吧文本具有信息含量、情绪与关注存在交互、词典与文本挖掘可度量情绪。缺口在于：质量门控与度量定义在同一设计中常交代不清；演示性工作缺少规范的 Fama–MacBeth / Logit；噪声治理常被省略。本课题据此补齐。

## 研究内容 *

一、问题表述与研究假设

研究对象：个股 \(i\)、交易日 \(t\) 的情绪因子 \(S_{i,t}\)，与未来 \(h\in\{1,3,5\}\) 日收益 \(r_{i,t+h}\)、涨跌 \(y_{i,t+h}\)。信息集仅用 \(t\) 日及以前信息。主假设：经质量筛选后的 \(S_{i,t}\) 在控制滞后收益与关注度后具有显著预测力；相对词典基线可报告差异。识别边界：可预测性，非因果。

二、数据治理与文本质量筛选

主采集东方财富股吧用户讨论。剔除过短灌水、广告荐股、纯资讯标题与页面壳等无效文本；完成去重、字段校验与交易日历对齐，形成可用帖文库。

三、情绪度量与日度因子

帖级得到 \(s_d\in[-1,1]\)：词典法为可解释基线；文本挖掘评分为主路径。日度主报告因子：文本挖掘情绪均值 \(S^{\mathrm{tm}}\)、看涨指数 \(Bullishness=\ln[(1+B)/(1+S)]\)；词典日度均值作基线；简单均值与影响力加权作聚合稳健性对照。可引入关注代理 \(M=\ln(1+|D|)\)。

四、检验模型

（1）Fama–MacBeth：\(r_{i,t+h}=a_t+b_t S_{i,t}+\mathbf{c}_t'\mathbf{X}_{i,t}+e_{i,t}\)，对 \(\{b_t\}\) 取均值并报 Newey–West t；主报告对主因子及词典基线、\(h=1/3/5\) 出表。  
（2）Logit：\(P(y=1)=\Lambda(\alpha+\beta S+\boldsymbol{\gamma}'X)\)，报告 β、AUC、准确率。  
（3）稳健性：Walk-Forward、Winsorize、子集、超额收益替换等。

五、预期产出

情绪—行情合并面板、主结果表与稳健性结果、毕业论文。

## 研究方法、手段及步骤 *

### 研究方法：

文献界定 → 固定问题与基本模型 → 构造词典/文本挖掘/看涨指数等因子 → 估计 Fama–MacBeth 与 Logit → 稳健性与样本外评估 → 比较文本挖掘因子相对词典基线是否更有效。以可预测性检验为主。

### 研究手段：

Python 数据处理；股吧文本采集与清洗；词典统计与文本挖掘评分；Fama–MacBeth、Logit；表格与版本管理保证复现。

### 研究步骤：

（1）开题：写清问题表述与基本模型，知网复核文献。  
（2）数据：采集、质量筛选、与行情对齐。  
（3）因子：导出主因子与基线因子。  
（4）实证：FM（h=1/3/5）与 Logit 出表。  
（5）稳健性、论文撰写与答辩。
