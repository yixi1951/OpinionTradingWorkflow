## 本选题的意义及国内外发展状况 *

### 本选题的意义：

社交媒体与财经社区（股吧、雪球、微博、财经门户评论等）产生的用户生成内容体量大、时效强，但噪声高、结构松散，难以直接服务于投资决策与学术检验。行为金融与金融科技交叉研究表明，投资者关注与文本情绪可能影响短期价格形成；与此同时，工程上已具备多源采集与情感打分能力，却缺少在统一流水线上对「不同情绪量化方式」与「规范计量模型」的系统对照。本课题依托已实现的 OpinionTradingWorkflow 实验平台（多平台舆情采集、词典/LLM 级联打分、回测与 Walk-Forward），研究个股社交媒体情绪对未来 1–5 个交易日收益与涨跌方向的预测力，比较简单均值、影响力加权、词典基线、LLM 打分与 Antweiler 看涨指数等量化方案，并采用 Fama–MacBeth 截面回归与 Logit 分类进行统计检验。课题目标不是承诺实盘超额收益，而是形成可复现、可解释、可答辩的「度量—模型—检验」闭环，为理解舆情因子有效性边界提供实证证据，同时沉淀可运行的数据处理与实验工程，具有明确的理论与实践价值。

### 国内外发展状况：

国外经典研究方面，Antweiler 与 Frank（2004）基于雅虎财经留言板构造看涨指数等指标，讨论网络讨论与市场活跃度、波动及收益的关系，为社交媒体文本进入资产定价实证提供了方法范式[1]。其后大量文献在不同市场与数据源上拓展情绪度量、关注度代理与预测窗口设定，逐步形成「帖级打分—日度聚合—收益回归/分类」的研究路径。

国内方面，段江娇等从股吧文本出发讨论信息含量，强调讨论活跃度与情绪方向对市场变量的可识别关联[2]；杨晓兰等指出情绪效应常与本地关注交互，高关注状态下冲击更强[3]。管理科学学报相关工作进一步突出开盘前情绪对开盘价等短窗价格的影响，提示情绪时间戳须与交易日历严格对齐[4]。姚加权等提出中文金融情绪词典，为中文财经文本提供可复现的词典基线[5]；万漪萍等则从机器学习情绪打分角度讨论股吧情绪与短期收益关系[6]。王高山等强调影响力加权情绪相对简单均值的优势，提示灌水帖会稀释算术平均[7]。尹海员等引入 Bi-LSTM 等序列模型刻画股吧情绪动态与泡沫类现象，说明情绪具有时序结构[8]。徐维军等将文本情绪嵌入 Black–Litterman 框架，拓展了情绪信号在资产配置中的应用[9]。张维等对社交媒体与资本市场研究进行综述，提醒识别策略、内生性与数据质量等方法论边界[10]。

综合来看，既有文献已分别证明股吧/社媒文本具有信息含量、情绪与关注存在交互、词典与机器学习可度量情绪、加权聚合往往优于简单均值、短期窗口更敏感。但仍存在三方面不足：一是多数研究绑定单一平台或单一打分器，缺少同一工程流水线上的多度量对照；二是工程演示常止于「打分+可视化」，缺少规范的 Fama–MacBeth / Logit 与样本外协议；三是去重、Winsorize、质量门控等噪声治理在计量设定中常被省略。本课题拟以 OpinionTradingWorkflow 为统一实验床，补齐 Antweiler 看涨指数对照与 FM/Logit 正式计量，系统回答「何种情绪量化对 1–5 日预测更有效」。

## 研究内容 *

本课题主要研究多源社交媒体文本情绪的量化方法及其对个股短期收益/涨跌的预测能力，围绕「情绪如何量化」与「用什么模型检验」两个核心问题展开。主要内容如下：

一、多源舆情数据治理与交易日历对齐

采集股吧、雪球、微博、东方财富、新浪财经、抖音等平台与个股相关的公开文本，完成证券代码绑定、去重、质量门控（标题/时间/正文覆盖率、噪声率、fallback 率）以及非交易日并入下一交易日、盘前窗与全日窗区分等时间对齐，形成标的—日面板数据。

二、帖级打分与日度情绪因子对照体系

在帖级实现词典/关键词基线与 LLM 级联打分（Jev→DeepSeek→关键词，保留 score_source 溯源），并可选轻量 ML 对照；在标的—日层面构造简单均值、影响力/平台加权、Antweiler 看涨指数及关注代理（发帖量等），必要时引入情绪×关注交互，形成可对照的因子矩阵。

三、预测模型构建与稳健性检验

以未来 1/3/5 日收益为被解释变量开展 Fama–MacBeth 截面回归（控制规模、反转、关注等可得变量，报告 Newey–West 等稳健标准误）；以涨跌方向为标签开展 Logit 分类（报告 AUC/准确率等）；并结合 Walk-Forward、平台子集、Winsorize 与不同阈值设定进行稳健性检验。在时间允许时，可探索将情绪信号作为简化 Black–Litterman 观点输入的应用延伸，但不作为主检验替代。

## 研究方法、手段及步骤 *

### 研究方法：

研读股吧/社交媒体与资产定价相关文献，明确情绪量化定义与计量设定；在统一样本上对照多种情绪因子；编写并运行实验代码，分析回归与分类结果，得出关于预测力与度量差异的结论。技术路线为：多源采集 → 清洗去重与质量门控 → 帖级打分（词典∥LLM）→ 日度聚合（Mean/影响力加权/Bullishness）→ 与行情合并生成 1/3/5 日收益与涨跌标签 → Fama–MacBeth 与 Logit → Walk-Forward 与稳健性 → 论文图表与系统可解释输出。研究以可预测性检验为主，审慎声称因果。

### 研究手段：

阅读相关论文，编写程序，主要采用以下工具与平台：

数据采集与处理：Python 3.10+、pandas/NumPy、requests 等；仓库内多平台采集与 HTML 解析模块。

情绪打分：OpinionTradingWorkflow 现有级联路径（Jev / DeepSeek / 关键词词典）；可选离线 ML 基线；配置见 `config/settings.yaml`。

计量与评估：拟新增 Fama–MacBeth、Logit 实验脚本；复用已有 `evaluate_signals`、`walk_forward`、`factor_backtest`（含 IC、`ret_1/3/5d`）等模块。

工程与展示：Git + pytest；Streamlit/Next 看板用于证据链展示；实验中间结果以 CSV/JSONL/Markdown 落盘保证可复现。

### 研究步骤：

（1）文献调研与开题准备：用学校 VPN 在知网/维普复核主引文献卷期页码与全文表述，定稿开题并明确样本边界与伦理说明。

（2）数据积累与面板构建：稳定运行采集与质量门控，完成小股票池到可扩展股票池的标的—日情绪与行情合并面板。

（3）情绪量化对照实现：落地 Mean / 影响力加权 / 词典 / LLM / Bullishness 等因子导出，完成去重、Winsorize 与盘前窗设定。

（4）主实证：实现并运行 Fama–MacBeth（h=1/3/5）与 Logit，加入控制变量与情绪×关注扩展，形成主结果表。

（5）稳健性、系统整理与论文撰写：完成 Walk-Forward 与子样本检验，整理可复现实验包与可解释输出，撰写毕业论文并准备答辩。
