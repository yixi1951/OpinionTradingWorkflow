# 开题落地实施清单（当前进度）

更新时间：以仓库提交为准。

## 策略定稿（必须遵守）

```
股吧等 UGC 采集
    → OpenClaw 免费模型验真 / 筛噪（不作论文主打分）
    → Jev / DeepSeek 正式打分（score_source = jev | deepseek）
    → 导出 sent_llm / Bullishness → Fama–MacBeth + Logit
```

- **OpenClaw**：只负责采集侧可读性/真实性门控（`openclaw_validated`），临时分写在 `openclaw_score`。  
- **打分**：只用 **Jev 或 DeepSeek**；关键词、影响力加权、平台加权**不是**打分替代，加权仅作聚合稳健性。  
- **面板**：`sent_llm` 只平均 `score_source∈{jev,deepseek}` 的帖；keyword/openclaw 不计入主 LLM 因子。

### 怎么跑（推荐顺序）

```bash
# 0) 采集（已有大量 raw 可跳过）
PYTHONPATH=src python3 scripts/crawl_guba_api_bulk.py --with-extra-symbols \
  --max-pages 45 --delay 0.3 --stop-before 2026-09-15

# 1) OpenClaw 免费模型验真（需 OPENCLAW_URL / 本地 gateway）
OPENCLAW_URL=http://127.0.0.1:18789 PYTHONPATH=src \
  python3 scripts/validate_raw_openclaw.py --since 2026-11-01 --max-total-rows 400

# 或爬取时顺带验真：
PYTHONPATH=src python3 scripts/crawl_guba_raw.py --with-openclaw ...

# 2) Jev / DeepSeek 正式打分（密钥注入后；省着用）
export SCORING_MODE=ai
export SCORING_PROVIDER=jev,deepseek
export JEV_API_KEY=...          # 或 TYPESAFE_API_KEY
export DEEPSEEK_API_KEY=...     # Jev 不可用时的正式打分路径
PYTHONPATH=src python3 scripts/rescore_raw_cascade.py \
  --since 2026-11-18 --until 2026-11-21 \
  --batch-size 4 --max-total-rows 80 --per-symbol 1

# 3) 面板 + FM/Logit
python3 -m opinion_trading.main --mode export_sentiment_panel --config config/settings.yaml
python3 -m opinion_trading.main --mode thesis_models --config config/settings.yaml \
  --price-file data/reports/price_history_cache.csv
```
