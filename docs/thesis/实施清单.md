### 怎么跑

```bash
# 1) 从 data/raw 导出标的—日情绪对照面板
python -m opinion_trading.main --mode export_sentiment_panel --config config/settings.yaml

# 2) 接行情跑 FM + Logit（默认读 data/reports/sentiment_panel.csv，没有则现算）
python -m opinion_trading.main --mode thesis_models --config config/settings.yaml \
  --price-file data/reports/price_history_cache.csv
```

输出：`data/reports/thesis_fama_macbeth.csv`、`thesis_logit.csv`、`thesis_models.md`。
