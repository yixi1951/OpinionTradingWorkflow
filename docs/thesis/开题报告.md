## 一、选题背景与研究意义

### 1.1 选题背景

资本市场价格形成不仅依赖财报与宏观数据，也显著受到投资者关注与情绪冲击。股吧等 UGC 体量大、时效强、噪声高。经典研究（Antweiler & Frank，2004；国内《金融研究》《管理科学学报》等）表明网络讨论与文本情绪具有信息含量，但也反复提醒：**数据质量门控**与**度量定义**决定结论可信度。

本课题依托 `OpinionTradingWorkflow`，把毕设主线收束为：

> **采集 UGC → OpenClaw 免费模型验真/筛噪 → Jev / DeepSeek 正式打分 → 日度因子 → Fama–MacBeth / Logit。**

不做「只爬不验」「用关键词/加权代替 LLM 打分」的捷径。

### 1.2 研究意义

| 层面 | 意义 |
|------|------|
| 数据 | 把 OpenClaw 免费模型明确为**验真层**，回应综述对噪声与数据质量的关切。 |
| 度量 | 以 Jev/DeepSeek 为正式打分，词典作可解释基线，加权仅作聚合稳健。 |
| 检验 | 用 FM + Logit + Walk-Forward 形成可复现测评闭环，服务论文而非实盘承诺。 |

### 1.3 问题表述（开题必须先写清）

**总问题（P）：** 经真实性门控后的社交媒体文本情绪，能否预测未来 1/3/5 个交易日收益与涨跌？Jev/DeepSeek 因子相对词典基线是否更有效？

| 编号 | 子问题 | 可检验含义 |
|------|--------|------------|
| **P1 验真** | 数据是否可信？ | OpenClaw 免费模型筛掉不可解析/噪声帖后，可用样本如何刻画 |
| **P2 打分** | 情绪如何量化？ | Jev/DeepSeek 帖级分 → Q4 \(S^{llm}\) / Q5 Bullishness（Q3 词典基线） |
| **P3 测评** | 有无预测力？ | FM（收益）+ Logit（涨跌）；Walk-Forward 等稳健性 |

**主假设：** 验真通过且由 Jev/DeepSeek 打分的 \(S_{i,t}\)，在控制滞后收益与关注后，预测系数显著；相对词典基线可报告差异。

**角色分工：** OpenClaw = 验真；Jev/DeepSeek = 正式打分；关键词/影响力加权 ≠ 打分替代。

**样本边界：** 股吧主源；沪深300约 30–70 只；主报告简单收益，稳健性补超额收益。  
**识别边界：** 可预测性，非因果。

## 二、国内外研究现状（精选十篇主线）

以下十篇作为开题主引；完整题录约百篇级公开检索库见前期整理（`corpus-100` 公开摘要级，正式开题前需知网复核）。

### 2.1 信息含量与关注交互

1. **段江娇等，《金融研究》2017——股吧信息含量**  
   强调股吧文本并非纯噪声，讨论活跃度与情绪方向对收益/波动具有可识别关联。启示：情绪因子应与**发帖量、讨论强度**一并考察，避免只看均值分数。

2. **杨晓兰等，《金融研究》2016——情绪×本地关注**  
   情绪效应常与关注度交互：高关注状态下情绪冲击更强。启示：模型中可加入**关注代理变量**（帖量、平台覆盖数）及交互项。

3. **《管理科学学报》2018——股评情绪；开盘前情绪→开盘价**  
   突出**交易时段对齐**：开盘前累积情绪对开盘价/隔夜收益更敏感。启示：情绪时间戳需对齐交易日历；区分盘前窗与全日窗。

### 2.2 情绪词典、机器学习与加权

4. **姚加权等，《管理科学学报》2021——中文金融情绪词典**  
   为中文金融文本提供可复现词典基线。启示：毕设需保留**词典/关键词路径**作为可解释对照，而不能只有黑盒 LLM。

5. **万漪萍等，《金融市场研究》2024——股吧 ML 情绪与短期收益**  
   机器学习情绪与短期收益关系的新近证据。启示：主检验窗口放在 **1–5 日短期**；ML/LLM 打分与词典打分对照。

6. **王高山等——影响力加权情绪优于简单均值**  
   简单算术平均易被灌水帖稀释；按阅读/点赞/用户影响力加权更稳。启示：聚合层实现 **mean vs influence-weighted** 对照实验。

7. **尹海员等，《管理学报》2022——Bi-LSTM 股吧情绪与泡沫**  
   序列模型捕捉情绪动态与泡沫类极端状态。启示：可选扩展为序列打分或情绪动量特征；本科阶段以对照实验为宜，不作唯一主模型。

### 2.3 组合应用与综述、跨市场经典

8. **徐维军等，《运筹学学报》2022——文本情绪进 Black–Litterman**  
   将文本观点嵌入贝叶斯资产配置。启示：若时间允许，可将情绪信号转为 BL 观点向量做**应用章**；主检验仍以预测力为准。

9. **张维等，《计量经济学报》2022——社交媒体与资本市场综述**  
   梳理识别策略、内生性与数据质量问题。启示：开题与正文需明确**因果边界**（本课题以可预测性/相关预测为主，审慎声称因果）。

10. **Antweiler & Frank (Journal of Finance, 2004)**  
    提出讨论板消息的看涨指数等经典构造，并关联市场活跃度与波动。启示：实现 **Bullishness 类指标**作跨文献对照；若条件允许，A 股社媒与美股社媒做方法学对照（非必须同一结论）。

### 2.4 研究评述与本课题切入点

既有文献已分别证明：股吧有信息含量、情绪与关注交互、词典与 ML 可度量情绪、加权优于均值、短期窗口更敏感。缺口在于：

- 多数研究绑定单一平台或单一打分器，**缺少在同一工程流水线上的多度量、多模型对照**；  
- 工程演示项目常止于“打分+看图”，**缺少规范的截面回归 / Logit / 样本外协议**；  
- 噪声治理（去重、Winsorize、质量门控）在计量设定中常被省略。

本课题切入点：**以 OpinionTradingWorkflow 为统一实验床，系统比较情绪量化方案，并用 Fama–MacBeth + Logit 检验 1–5 日预测力，辅以 Walk-Forward。**

## 三、研究目标与研究内容

### 3.1 研究目标

1. 构建面向个股的多源社交媒体情绪日度因子体系（帖级打分 → 标的—日聚合）。  
2. 在统一样本上比较至少四类情绪度量：简单均值、影响力加权、词典/关键词、LLM/ML；并实现 Antweiler 风格看涨指数。  
3. 用 **Fama–MacBeth 截面回归**检验情绪对未来 1/3/5 日收益的预测力；用 **Logit（或 Probit）**检验对涨跌方向的分类能力。  
4. 完成去噪与稳健性：文本去重、情绪 Winsorize、平台子集、不同阈值；样本外 Walk-Forward。  
5. 形成可复现实验报告与开源工程文档，支撑毕设论文与答辩。

### 3.2 研究内容（章节对应建议）

| 模块 | 内容 |
|------|------|
| 数据与治理 | 多平台采集、证券代码绑定、交易日历对齐、质量报告（覆盖率/噪声率/fallback） |
| 情绪量化 | 见第四节（核心） |
| 预测模型 | 见第五节（核心） |
| 实证结果 | 全样本、子样本（高关注/盘前）、度量对照、稳健性 |
| 工程实现 | 流水线、配置项、可解释输出（评论依据） |
| （可选）应用延伸 | 情绪观点 → 简化 Black–Litterman 或纸面回测 |

### 3.3 拟创新点（本科可行表述）

1. **同一流水线上的多情绪度量对照实验**（均值 / 影响力加权 / 词典 / LLM + Bullishness）。  
2. **计量与工程打通**：FM 回归 + Logit + Walk-Forward 与现有信号评估、证据链 UI 一体。  
3. **显式噪声协议**：去重、Winsorize、质量门控写入研究设计，而非事后脚注。

## 四、情绪如何量化（文献映射 → 可执行定义）

### 4.1 帖级（document-level）打分

对采集到的每条帖文 \(d\)，得到情绪分数 \(s_d \in [-1,1]\)（或映射到该区间）：

| 方案 | 文献依据 | 本课题实现路径 | 角色 |
|------|----------|----------------|------|
| A. 关键词 / 中文金融情绪词典 | 姚加权等（2021） | keyword 路径 | **可解释基线（非主打分）** |
| B. OpenClaw 免费模型 | 工程 | `validate_raw_openclaw.py` / 爬取 `--with-openclaw` | **验真/筛噪，不作论文主打分** |
| C. Jev / DeepSeek 正式打分 | 工程 + ML 文献精神 | `scoring.provider=jev,deepseek` | **论文主打分路径** |
| D. 序列模型帖级/日级（可选） | 尹海员等（2022）Bi-LSTM | 时间有限则作扩展 | 扩展 |

强制要求：论文主结果仅保留 `score_source∈{jev,deepseek}`；OpenClaw 写 `openclaw_validated` / `openclaw_score`。

### 4.2 标的—日聚合（symbol–day）

对股票 \(i\)、交易日 \(t\)，集合 \(D_{i,t}\) 为当日（或盘前窗）相关帖：

1. **简单均值（Mean）**  
   \[
   S^{mean}_{i,t} = \frac{1}{|D_{i,t}|}\sum_{d\in D_{i,t}} s_d
   \]

2. **影响力加权（Influence-weighted）**——王高山等  
   权重 \(w_d\) 可用：阅读数、评论数、点赞，或平台先验权重 × 文本长度惩罚灌水。  
   \[
   S^{inf}_{i,t} = \frac{\sum_d w_d s_d}{\sum_d w_d}
   \]
   现有 `platform_weights`（股吧/东财更高）可并入 \(w_d\)。

3. **Antweiler 看涨指数（Bullishness）**——Antweiler & Frank（2004）  
   将帖分为看涨 \(B\)、看跌 \(S\)（可由 \(s_d\) 阈值或三分类得到）：  
   \[
   Bullishness_{i,t} = \ln\frac{1+B_{i,t}}{1+S_{i,t}}
   \]
   另可报告同意度 Agreement、总消息数 \(M_{i,t}=\ln(1+|D_{i,t}|)\) 作为关注代理。

4. **平台加权后再截面标准化**  
   先按平台聚再按 `platform_weights` 合成，或对 \(S_{i,t}\) 做横截面 z-score，减轻一日全市场同涨同跌噪声。

### 4.3 噪声与时间对齐（写入研究设计）

| 步骤 | 做法 | 文献/工程依据 |
|------|------|----------------|
| 去重 | 日内指纹去重；可选跨日/近重复 | 数据质量；仓库已有 dedup 能力 |
| Winsorize | 对极端 \(s_d\) 或日度 \(S\) 分位裁剪 | 工程 `sentiment_winsorize`；稳健性 |
| 质量门控 | 标题/时间/正文覆盖率、噪声率、fallback 率 | 段文“信息含量”前提是可用文本 |
| 交易日历 | 非交易日并入下一交易日；盘前窗单独因子 | 管科学 2018 开盘前情绪 |
| 关注交互 | \(S\times M\) 或高帖量子样本 | 杨晓兰等（2016） |

### 4.4 毕设默认对照矩阵（必须跑完）

| 编号 | 情绪因子 | 说明 |
|------|----------|------|
| Q1 | \(S^{mean}\) | 简单均值（聚合对照） |
| Q2 | \(S^{inf}\) | 影响力/平台加权（**聚合稳健，非打分**） |
| Q3 | \(S^{dict}\) | 词典/关键词基线 |
| Q4 | \(S^{llm}\) | **仅 Jev/DeepSeek 帖** |
| Q5 | \(Bullishness\) | Antweiler 指数（主报告基于 LLM 帖） |
| Q6 | \(M\) 或 \(S\times M\) | 关注及交互 |

主报告以 **Q4/Q5** 为核心，Q3 为基线；Q1/Q2/Q6 进稳健性。

## 五、用什么模型（检验框架）

### 5.1 被解释变量与预测窗口

- 收益：股票 \(i\) 在 \(t\) 收盘后持有到 \(t+h\) 的收益 \(r_{i,t+h}\)，\(h\in\{1,3,5\}\)（交易日）。  
- 方向：\(y_{i,t+h}=\mathbf{1}\{r_{i,t+h}>0\}\)（或相对市场超额收益符号）。  
- **严格避免前视**：情绪只用 \(t\) 日可得信息；价格对齐采用 T+1 / merge_asof 协议（与现有 `evaluate_signals` 一致）。

### 5.2 主模型 A：Fama–MacBeth 截面回归

对每个交易日 \(t\) 做截面回归，再对系数时间序列取均值并算 Newey–West 等稳健标准误：

\[
r_{i,t+h} = a_t + b_t\, S_{i,t} + \mathbf{c}_t'\mathbf{X}_{i,t} + e_{i,t}
\]

**控制变量 \(\mathbf{X}\)**（按数据可得性取舍）：

- 规模、反转（昨日收益）、换手/波动代理；  
- 关注 \(M_{i,t}\)；  
- （可选）市场 Beta 或行业哑变量。

**报告：** \(\bar{b}\)、t 值、不同 \(h\)、不同 \(S\) 定义下的系数差异。  
**文献角色：** 与段江娇、杨晓兰、管科学开盘前研究及短窗 ML 文献对话。

### 5.3 主模型 B：Logit 涨跌分类

\[
P(y_{i,t+h}=1)=\Lambda(\alpha + \beta S_{i,t} + \boldsymbol{\gamma}'\mathbf{X}_{i,t})
\]

**报告：** \(\beta\) 显著性、AUC / 准确率 / 精确率-召回、相对无情绪模型的提升。  
与工程侧“方向准确率、胜率”指标对齐，便于论文与系统演示一致。

### 5.4 辅模型与扩展（时间允许）

| 模型 | 用途 | 文献 |
|------|------|------|
| 面板固定效应 / 聚类稳健 SE | 稳健性 | 综述（张维等）方法提醒 |
| 情绪动量、滚动标准化 | 动态特征 | 尹海员等序列思想（简化版） |
| Black–Litterman 观点输入 | 应用章：把 \(S\) 转为观点收益率 | 徐维军等（2022） |
| 纸面回测 + Walk-Forward | 经济意义与过拟合约束 | 工程已有 WF；非 FM 替代，而是补充 |

### 5.5 模型选择结论（开题一句话）

> **情绪量化**采用“词典基线 + LLM 主路径 + 均值/影响力加权 + Bullishness”对照；  
> **预测检验**以 **Fama–MacBeth（收益）+ Logit（方向）** 为主模型，以 Walk-Forward 与稳健性为必做，以 BL/序列模型为可选应用扩展。

## 六、技术路线与实验平台

### 6.1 总体路线

```text
多源采集（股吧/雪球/微博/东财/新浪/抖音）
    → 清洗 / 去重 / 质量门控 / 交易日历对齐
    → 帖级打分（词典 ∥ LLM 级联 ∥ 可选 ML）
    → 标的—日聚合（Mean / Inf / Bullishness / 平台加权）
    → 与行情合并（未来 1/3/5 日收益与涨跌标签）
    → FM 截面回归 + Logit
    → Walk-Forward / 子样本 / 稳健性
    → 论文图表 + 系统可解释面板
```

### 6.2 与 OpinionTradingWorkflow 的模块映射

| 研究环节 | 仓库落点（现状 / 拟扩展） |
|----------|---------------------------|
| 采集 | `platform_sentiment_real` 等；`config/settings.yaml` 平台与权重 |
| 验真（已有） | OpenClaw 免费模型：`validate_raw_openclaw.py` / 爬取 `--with-openclaw` → `openclaw_validated` |
| 打分（已有） | 正式路径 `jev → deepseek`（`rescore_raw_cascade.py`）；keyword 仅基线/占位，**不进 `sent_llm`** |
| 聚合（已有） | 平台内均值 + `platform_weights`；时效半衰加权；影响力权重——均属聚合稳健，非打分替代 |
| 聚合（拟扩展） | **导出对照因子**：纯 Mean / 强化 Inf / **Antweiler Bullishness**（仓库尚无）及关注代理 \(M\) |
| 存储 | `data/memory/*.jsonl`、`data/raw`、质量报告；`score_source` 溯源 |
| 收益与因子评估（已有） | `evaluate_signals`、`walk_forward`；`factor_backtest` / `factor_metrics`（`ret_1/3/5d`、IC/ICIR、分组多空） |
| 计量主模型（拟新增） | **Fama–MacBeth、Logit、Black–Litterman 均尚未实现** → 新增 `scripts/` 或 `core/` 计量入口，复用已有 1/3/5 日收益面板 |
| 展示 | Streamlit / Next 看板；评论依据 Tab |

**毕设增量边界（相对现状）：** 不是从零搭流水线，而是补齐文献要求的 **Bullishness 对照 + FM/Logit 正式计量**，并把已有影响力加权与 IC 评估升格为论文主表。

### 6.3 样本与范围（开题可承诺边界）

- **主样本：** A 股，股票池由小样本蓝筹/沪深 300 流动子集起步，视采集稳定性扩容。  
- **主平台：** 股吧 + 雪球为文本主源，其余平台作稳健性或权重敏感性。  
- **对照市场（可选）：** 美股社媒方法学对照，不作为硬性交付。  
- **不承诺：** 稳定实盘超额、完整因果识别、全市场分钟级行情。

### 6.4 评价指标

- 统计：FM 系数与 t 值；Logit AUC/准确率；IC（Spearman/Pearson）。  
- 经济（辅助）：纸面净值、夏普类指标、最大回撤（明确成本假设）。  
- 工程：质量报告达标率、`score_source` 覆盖、实验可复现清单。

## 十一、开题一页纸摘要（可直接发给导师）

**题目：** 基于社交媒体舆情的个股短期收益可预测性研究  

**问题：** 经真实性门控后的股吧文本情绪，能否预测个股未来 1–5 日收益与涨跌？Jev/DeepSeek 相对词典基线是否更有效？  

**流水线：** 采集 UGC → **OpenClaw 免费模型验真** → **Jev / DeepSeek 正式打分** → 日度因子（主：LLM 均值与 Bullishness；基线：词典）→ Fama–MacBeth + Logit。  

**不做：** 用关键词或影响力加权冒充正式打分；不声称因果、不承诺实盘超额。  

**平台：** OpinionTradingWorkflow（已通 Jev=`jevmodel.org`、DeepSeek failover）。  

**交付：** 主结果表、稳健性、可复现代码与毕业论文。
