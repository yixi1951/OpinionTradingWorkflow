## 一、问题表述（先写清）

### 1.1 总问题（P）

在可控的 A 股**个股—交易日**样本上，经质量/真实性门控后的社交媒体（以东方财富**股吧**为主）文本情绪，能否预测未来 **1 / 3 / 5** 个交易日的：

- 收益水平（连续因变量）；  
- 涨跌方向（二分类因变量）？

进一步：用 **Jev / DeepSeek** 得到的情绪因子，相对**词典基线**是否更有效？

### 1.2 子问题

| 编号 | 问题 | 含义 |
|------|------|------|
| P1 验真 | 数据是否可用？ | 如何降低灌水、空文、新闻壳与不可解析噪声 |
| P2 打分 | 情绪如何量化？ | 帖级分数如何得到，并聚合成日度因子 |
| P3 测评 | 有无预测力？ | FM（收益）与 Logit（涨跌）系数是否显著、是否稳健 |

### 1.3 边界（开题承诺）

| 项目 | 设定 |
|------|------|
| 文本源 | 股吧为主 |
| 股票池 | 沪深300流动子集，约 30–70 只 |
| 因变量 | 主报告：个股未来 h 日简单收益；稳健性：相对沪深300超额收益 |
| 识别 | **可预测性**检验，**不声称因果** |
| 角色 | OpenClaw = 验真（不作主打分）；**Jev/DeepSeek = 正式打分**；关键词/影响力加权 ≠ 打分替代 |

**主假设：** 经门控并由 Jev/DeepSeek 打分得到的日度情绪 \(S_{i,t}\)，在控制滞后收益与关注度后，对 \(r_{i,t+h}\) / 涨跌具有显著预测力；相对词典基线可报告差异。

> 说明（回应「用 AI 打分还要不要模型」）：  
> **LLM（Jev/DeepSeek）只是帖级打分器**；论文的「基本模型」是下面的**度量定义 + Fama–MacBeth / Logit 检验框架**，二者缺一不可。

## 二、基本模型

### 2.1 总体框架（三层）

```
采集 UGC（股吧）
  → 质量门控 / OpenClaw 验真
  → Jev（优先）→ DeepSeek（备援）正式打分
  → 日度情绪因子 S_{i,t}
  → Fama–MacBeth（收益）+ Logit（涨跌）
```

| 层 | 内容 | 论文位置 |
|----|------|----------|
| A 数据与验真 | 采集 + 去噪 + OpenClaw 可读性/真实性门控 | 第3章 |
| B 情绪度量 | 帖级 \(s_d\) → 日度 \(S_{i,t}\)（主：LLM；基线：词典） | 第4章 |
| C 检验模型 | FM + Logit + 稳健性 | 第5–6章 |

### 2.2 帖级打分

对帖文 \(d\)，得到情绪分数 \(s_d\in[-1,1]\)：

- **正式路径：** Jev（jevmodel.org）优先；失败则 DeepSeek；保留 `score_source∈{jev,deepseek}`  
- **验真路径：** OpenClaw 仅标记 `openclaw_validated`，**不进入**主因子  
- **基线路径：** 中文金融情绪词典 / 关键词（可解释对照）

### 2.3 日度因子（标的 i、交易日 t）

设 \(D_{i,t}\) 为当日相关帖集合。主报告因子：

1. **Q4　\(S^{llm}_{i,t}\)**（主）  
   仅对 `jev|deepseek` 帖取均值：
   \[
   S^{llm}_{i,t}=\frac{1}{|D^{llm}_{i,t}|}\sum_{d\in D^{llm}_{i,t}} s_d
   \]

2. **Q5　Bullishness**（主，Antweiler 型）  
   由 LLM 帖划分为看涨数 \(B\)、看跌数 \(S\)：
   \[
   Bullishness_{i,t}=\ln\frac{1+B_{i,t}}{1+S_{i,t}}
   \]

3. **Q3　\(S^{dict}_{i,t}\)**（基线）词典日度均值  

4. **Q1/Q2**（稳健）简单均值 / 影响力加权——**聚合对照，不作打分替代**

另可报告关注代理 \(M_{i,t}=\ln(1+|D_{i,t}|)\) 及情绪×关注交互。

### 2.4 检验模型（测评）

**（1）Fama–MacBeth（收益）**  
对每个交易日 \(t\)、预测窗 \(h\in\{1,3,5\}\)：
\[
r_{i,t+h}=a_t+b_t S_{i,t}+c_t'X_{i,t}+e_{i,t}
\]
对 \(\{b_t\}\) 取时间均值，报告 Newey–West t。  
控制变量 \(X\) 可含：滞后收益、关注度 \(M\) 等可得变量。

**（2）Logit（涨跌）**  
\[
P(y_{i,t+h}=1)=\Lambda\!\left(\alpha+\beta S_{i,t}+\gamma'X_{i,t}\right)
\]
报告 \(\beta\)、AUC、准确率。

**（3）稳健性**  
Walk-Forward；Winsorize；平台/子集；超额收益替换简单收益。

### 2.5 主报告对照矩阵

| 编号 | 因子 | 角色 |
|------|------|------|
| Q4 | \(S^{llm}\) | **主结果** |
| Q5 | Bullishness | **主结果** |
| Q3 | \(S^{dict}\) | 基线对照 |
| Q1/Q2 | 均值 / 影响力加权 | 聚合稳健（附录） |

## 三、选题意义与文献定位（摘要）

股吧 UGC 时效强、噪声高。既有文献已讨论信息含量、情绪×关注、词典与机器学习打分、Bullishness 等（Antweiler & Frank, 2004；段江娇等, 2017；杨晓兰等, 2016；姚加权等, 2021；万漪萍等, 2024 等）。常见缺口是：噪声门控与正式 LLM 打分脱节，或用关键词/加权冒充打分，又缺少规范的 FM/Logit。本课题以「验真 → Jev/DeepSeek 打分 → FM/Logit」补齐，形成可复现闭环；**不承诺实盘超额收益**。
