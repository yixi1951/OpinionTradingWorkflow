## 一、问题表述

### 1.1 总问题（P）

在可控的 A 股**个股—交易日**样本上，经质量筛选后的社交媒体（以东方财富**股吧**为主）文本情绪，能否预测未来 **1 / 3 / 5** 个交易日的：

- 收益水平（连续因变量）；  
- 涨跌方向（二分类因变量）？

进一步：基于文本挖掘得到的情绪因子，相对**词典基线**是否更有效？

### 1.2 子问题

| 编号 | 问题 | 含义 |
|------|------|------|
| P1 数据治理 | 数据是否可用？ | 如何识别并剔除灌水、空文、广告与资讯转载等无效文本 |
| P2 情绪度量 | 情绪如何量化？ | 帖级分数如何得到，并聚合成日度因子 |
| P3 预测检验 | 有无预测力？ | Fama–MacBeth（收益）与 Logit（涨跌）系数是否显著、是否稳健 |

### 1.3 边界

| 项目 | 设定 |
|------|------|
| 文本源 | 股吧为主 |
| 股票池 | 沪深 300 流动子集，**当前约 70 只（72 只）** |
| 文本窗口 | 约 2026-03 至 2026-11；原始帖约 5 万条，可用约 3.3 万条 |
| 因变量 | 主报告：个股未来 h 日简单收益；稳健性：相对沪深 300 超额收益 |
| 识别 | **可预测性**检验，**不声称因果** |
| 度量角色 | 词典 = 可解释基线；文本挖掘评分 = 主路径；看涨指数 = 经典对照；简单均值/影响力加权 = 聚合稳健对照 |

**主假设：** 经质量筛选后得到的日度情绪因子 \(S_{i,t}\)，在控制滞后收益与关注度后，对未来短期收益与涨跌具有显著预测力；相对词典基线可报告差异。

## 二、基本模型

### 2.1 总体框架

```text
股吧文本采集
  → 清洗、去重、无效帖剔除、交易日历对齐
  → 帖级情绪评分（词典 ∥ 文本挖掘）
  → 个股—日聚合（均值 / 加权 / 看涨指数）
  → Fama–MacBeth（收益）+ Logit（涨跌）
  → Walk-Forward 与稳健性
```

| 层 | 内容 |
|----|------|
| A 数据与治理 | 采集、去噪、质量筛选、日历对齐 |
| B 情绪度量 | 帖级 \(s_d\) → 日度 \(S_{i,t}\)（主：文本挖掘；基线：词典） |
| C 检验模型 | Fama–MacBeth + Logit + 稳健性 |

### 2.2 帖级情绪分数

对帖文 \(d\)，得到情绪分数 \(s_d\in[-1,1]\)（越大越偏多）：

| 方案 | 角色 |
|------|------|
| 词典 / 关键词 | 可解释基线 |
| 文本挖掘评分 | 主度量路径 |
| （可选）序列模型 | 扩展，非必须 |

质量筛选保证进入打分的文本可用，其本身不是情绪主度量。

### 2.3 日度因子（标的 i、交易日 t）

设 \(D_{i,t}\) 为当日相关帖集合。主报告因子：

1. **Q4　\(S^{\mathrm{tm}}_{i,t}\)**（主）　文本挖掘情绪日度均值  
2. **Q5　Bullishness**（主，Antweiler 型）  
   \[
   Bullishness_{i,t}=\ln\frac{1+B_{i,t}}{1+S_{i,t}}
   \]
3. **Q3　\(S^{\mathrm{dict}}_{i,t}\)**（基线）词典日度均值  
4. **Q1/Q2**（稳健）简单均值 / 影响力加权——聚合对照，不作度量替代  

另可报告关注代理 \(M_{i,t}=\ln(1+|D_{i,t}|)\) 及情绪×关注交互。

### 2.4 检验模型

**（1）Fama–MacBeth（收益）**  
对每个交易日 \(t\)、预测窗 \(h\in\{1,3,5\}\)：
\[
r_{i,t+h}=a_t+b_t S_{i,t}+\mathbf{c}_t'\mathbf{X}_{i,t}+e_{i,t}
\]
对 \(\{b_t\}\) 取时间均值，报告 Newey–West t。控制变量可含滞后收益、关注度 \(M\) 等。

**（2）Logit（涨跌）**  
\[
P(y_{i,t+h}=1)=\Lambda(\alpha+\beta S_{i,t}+\boldsymbol{\gamma}'\mathbf{X}_{i,t})
\]
报告 \(\beta\)、AUC、准确率。

**（3）稳健性**  
Walk-Forward；Winsorize；子集；超额收益替换简单收益。

### 2.5 主报告对照矩阵

| 编号 | 因子 | 角色 |
|------|------|------|
| Q4 | \(S^{\mathrm{tm}}\) | **主结果** |
| Q5 | Bullishness | **主结果** |
| Q3 | \(S^{\mathrm{dict}}\) | 基线对照 |
| Q1/Q2 | 均值 / 影响力加权 | 聚合稳健（附录） |

### 2.6 开题一句话

> **情绪度量**采用「词典基线 + 文本挖掘主路径 + 看涨指数」，辅以均值/影响力加权作聚合稳健；  
> **检验模型**以 **Fama–MacBeth（收益）+ Logit（方向）** 为主，以 Walk-Forward 与稳健性为必做。

## 三、选题意义与文献定位（摘要）

股吧文本时效强、噪声高。既有文献已讨论信息含量、情绪与关注交互、词典与文本挖掘、看涨指数等（Antweiler & Frank, 2004；段江娇等, 2017；杨晓兰等, 2016；姚加权等, 2021；万漪萍等, 2024 等）。常见缺口是：质量门控与度量定义在同一设计中交代不清，且缺少规范的 Fama–MacBeth / Logit。本课题以「数据治理 → 情绪度量 → 检验模型」补齐，形成可复现闭环；**不承诺实盘超额收益**。

## 四、研究内容与步骤（提纲）

1. 定稿问题 P / P1–P3 与基本模型（本文）  
2. 股吧采集、质量筛选，与行情、交易日历对齐  
3. 构造词典基线、文本挖掘情绪与看涨指数等日度因子  
4. 主实证：Fama–MacBeth（h=1/3/5）与 Logit 出表  
5. 稳健性、论文撰写与答辩
