## Design Context

**Product**: OpenClaw AI Picks — a Streamlit analytics dashboard for multi-platform stock sentiment, AI-scored picks, and backtest evaluation.

**Target audience**: Individual investors and quant-curious operators in China A-share / HK markets who monitor social sentiment (Guba, Xueqiu, Weibo) and want explainable AI picks, not black-box signals.

**Use cases**:
- Check today's Top 3 realtime picks and why each was chosen
- Inspect platform sentiment trends and contribution weights
- Read filtered user comments vs reference news
- Run monthly backtest / training evaluation

**Brand personality / tone**: Soft tactile minimal futurism — calm, warm, premium, and uncluttered. Dense data stays legible; chrome stays quiet. Matte warm neutrals over cold neon tech.

**Technical constraints**:
- Streamlit (`ui_dashboard.py`) with injected CSS from `ui/dashboard_styles.py` — no React/Tailwind stack
- Bilingual EN/ZH via `LANG` dict — do not break i18n keys
- Altair charts — keep chart theme aligned with CSS tokens
- Typography: lightweight Inter (explicit brand request)
- Motion: slow soft `transform`/`opacity` lifts (~480ms), respect `prefers-reduced-motion`
- Theme: light/dark warm-neutral palettes with sidebar toggle; persist via `?theme=`

**Differentiation**: A soft-future research desk — frosted glass cards, thin luminous borders, thin-line geometric accents, warm taupe accent — not teal neon terminals or purple SaaS gradients.

**Register**: Product UI (dashboard), not marketing landing page.
